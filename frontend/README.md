# Real Estate Buyer Portal - Frontend

## How to run the app

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment**:
   Copy `.env.example` to `.env` and fill in the values.
   ```bash
   cp .env.example .env
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

## Example flows

### Sign up → Login → Add Favorite
1. **Sign up**: Navigate to the Sign Up page and fill in the registration form.
2. **Login**: Once registered, go to the Login page and enter your credentials.
3. **Add Favorite**: Browse properties and click the heart icon on any property to add it to your favorites.
